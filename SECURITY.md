# Security policy

## Scope

LabLink is an educational prototype, not a production campus booking service. The public hosted demo uses fictional sample data and disposable, in-memory sandboxes. Do not submit real student information, credentials, or sensitive institutional data.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's **Report a vulnerability** feature for this repository when available, or contact the repository owner privately through their GitHub profile. Include affected versions, impact, and steps to reproduce. Avoid including real user data or secrets.

There is no guaranteed response time or production security support for this prototype.
